# ADR-0002：单容器交付，Go embed 托管前端

- 状态：已接受
- 日期：2026-10-24

## 背景

目标用户是自托管个人导航站用户，希望一键部署、低运维成本。多容器或前后端分离部署会提高运维复杂度。

## 决策

生产环境使用**单个应用容器**：

- Go 服务通过 `embed` 托管 Vue 构建产物与 REST API。
- SQLite 与上传目录挂载到 `/data` 持久化。
- 非 API、非静态资源路径回退到 `index.html`（SPA fallback）。
- **开发环境**前后端仍独立启动：后端 `go run`，前端 Vite（代理 `/api`）。

## 理由

- 单进程、低内存，适合小型 VPS。
- 同源托管避免跨域与 Cookie 问题。
- 运行时不需要 Node，镜像更小。
- 开发独立、生产统一，兼顾体验与运维。

## 影响

- 镜像构建为多阶段：先构建前端，再构建 Go（含 embed），最后精简运行层。
- 前端产物路径需与 Go embed 路径约定一致。
- 更新即替换整个镜像，需配套备份与迁移策略（见 ADR-0003）。

## 备选方案

- **前后端分离部署（Nginx + Go 两容器）**：运维更复杂，跨域与 Cookie 配置更多。
- **纯静态托管 + 外部 API**：不满足一键部署与数据持久化目标。
