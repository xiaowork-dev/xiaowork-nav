## 2. 视觉与交互特征（作为前端 UI 参考）

> 目标：**保留整体风格与使用习惯，不要求像素级还原**，允许按现代 UI/UX 规范优化。

### 2.1 首页结构（自上而下）

1. **顶部工具区**：右上角主题切换、设置、管理入口；移动端为左上角菜单按钮。
2. **时钟区**：大号时间 + 日期（参考实现中时钟为次要尺寸，截图版本无时钟，均属可配置）。
3. **搜索区**：居中搜索框，左侧搜索引擎图标切换，右侧搜索按钮；回车或点击搜索。
4. **分类分组区**：每个分类有标题（左侧文字），下方为图标磁贴网格。
5. **页脚**：站点信息。

### 2.2 分类与磁贴

- 分类为**分组标题 + 图标网格**；网格自动换行、左对齐。
- 每个网站为一个**磁贴**：上方为图标（圆角方块，白底），下方为名称文字。
- 参考实现磁贴尺寸约 58px、名称在下方居中；截图版本磁贴更大、卡片有浅色底。
- 图标来源：本地图片 / 远程 URL / 站点图标。
- 参考实现的分类示例：`常用`、`IP&DNS`、`AI & 智能`、`VPS/云服务器`、`邮箱`、`开发 & 编程`、`域名`、`其他导航`。

### 2.3 配色与主题

- 主背景：**紫蓝渐变**（`#303a83 → #464293 → #7752b0 → #be6b99` 类），叠加柔和光晕。
- 卡片/搜索框：半透明玻璃质感（`backdrop-filter: blur`）+ 白色描边。
- 强调色：蓝紫渐变按钮。
- 支持 **深色模式**（`night-mode`），配色整体加深。
- 文字：白色为主，次要信息降低不透明度。

### 2.4 交互习惯

- 点击磁贴在新标签打开站点。
- 搜索框支持选择搜索引擎。
- 管理员进入"编辑模式"后可**拖拽排序**、**新增/编辑/删除**分类与网站。
- 移动端：多列小磁贴（3–4 列），底部弹出式编辑表单。

### 2.5 管理端参考

- 参考实现通过"编辑模式"在首页直接操作；V2.0 改为**独立管理后台**（更清晰、更安全），首页保持纯浏览体验。

## 3. 从参考得出的 V2.0 设计约束

| 参考特征 | V2.0 落地 |
| --- | --- |
| 渐变背景 + 玻璃卡片 | 通过主题变量实现，`theme` 设置可切换 |

| 图标多来源 | `icon_type: none/url/upload/auto` |
| 移动端适配 | 响应式网格 + 触控排序替代 |

## 4. 数据迁移假设（待真实样本验证）

旧站数据暂不可得，先做如下**假设**并据此实现通用导入器：

```jsonc
// 假设的旧站 data.json 形态（未验证，仅用于设计导入器抽象）
{
  "categories": [
    {
      "name": "AI & 智能",
      "icon": "…",              // 可选
      "links": [
        { "name": "ChatGPT", "url": "https://chat.openai.com", "icon": "…" }
      ]
    }
  ]
}
```

导入器设计要求：

1. 以 `format` 字段区分来源：`xiaowork-nav-v1`（本系统导出）/ `legacy-v1`（旧站）。
2. 解析时对字段做**宽松映射**：`name/title`、`url/link/href`、`icon/iconUrl/favicon` 等常见别名均尝试识别。
3. **不覆盖已有数据**：默认 `skip` 冲突策略，需显式选择 `overwrite`/`rename`。
4. 全程在**单事务**内执行，失败回滚。
5. 提供**导入预览**（新增/冲突统计），供管理员确认。

> 待获得真实 `data.json` 后：补充字段映射表、编写针对性测试、以真实数据验证导入结果，并更新本文档与 `database-design.md` 第 5 节。
