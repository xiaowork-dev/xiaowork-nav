## 1. 背景与目标

V2.1.1 把侧栏移到了页面左边缘，但生产使用后反馈：**侧栏与主体之间存在大量空白、
深紫黑色侧栏与主页面渐变严重割裂、顶部导航/搜索框/侧栏/正文没有统一对齐关系，
整体像两个独立页面拼接**。

本次目标不是继续微调宽度、圆角或透明度，而是**重新检查滚动模式的整体布局结构**，
把它做成真正一体化的应用布局。

## 2. 根因分析

| 现象 | 根因 |
| --- | --- |
| 侧栏与主体之间大量空白 | `.rail-main__inner` 使用 `width: min(100%, 1200px)` + `margin: 0 auto`，在 `1fr` 主列内**二次居中**。1440px 下产生约 54px、1920px 下产生约 **254px** 的死空白 |
| 侧栏与渐变割裂 | 侧栏使用**独立深色实心背景** `rgba(26,21,58,.90)`（浅色主题同样是深色块），与页面渐变不是同一套背景体系 |
| 对齐关系缺失 | 顶部导航在**页面居中容器**内，侧栏与主体在另一套坐标系里；品牌、操作按钮、搜索框、分类标题分属三套不同的栅格 |
| 像两个页面拼接 | 以上三点叠加：一列是深色面板、一列是居中容器，中间还隔着空白 |

> 关键结论：问题出在**布局模型**（主列内二次居中 + 侧栏独立配色），
> 因此本次不做 margin/padding/position 修补，而是重构骨架与配色变量。

## 3. 结构重构（组件层面）

### 3.1 页面骨架

滚动模式改为**单一应用外壳**：整页一个 grid，左列固定为分类栏、右列占满剩余空间，
右列内部**不再做任何二次居中**。

```text
.page.page--rail            ← 全宽（width:100%; max-width:none; padding:0）
└── .shell                  ← grid: var(--rail-width) | minmax(0, 1fr)
    ├── .rail               ← 品牌行 + 分类标题 + 分类列表（sticky, 100vh, 独立滚动）
    └── .shell__main
        ├── .shell__topbar  ← 操作按钮（与品牌行同为 64px，形成统一对齐线）
        └── .shell__content ← 时钟 / 搜索框 / 分类（padding-inline: var(--shell-gutter)，无 max-width、无 auto 居中）
```

- 侧栏**从网站顶部（y=0）延伸至视口底部**，品牌标识移入侧栏顶部。
- 顶部操作按钮（布局切换 / 主题 / 登录 / 管理后台）位于右侧主内容区的顶栏。
- 手机上侧栏隐藏，顶栏重新显示品牌（同一 `BrandMark` 组件）。

### 3.2 组件拆分（消除重复，保证两套布局一致）

| 组件 | 作用 |
| --- | --- |
| `BrandMark.vue`（新） | 品牌标识：有 Favicon 用图片，否则用品牌渐变底 + 标题首字母（保证折叠态也有标识） |
| `HeaderActions.vue`（新） | 右上角操作区（布局切换 / 主题 / 登录 / 管理后台），两种布局共用同一套按钮 |
| `AppHeader.vue`（改） | 品牌 + 操作区（标签模式与加载/错误态使用） |
| `CategorySidebar.vue`（改） | 顶部增加品牌行，其余不变 |
| `ScrollLayout.vue`（改） | 渲染完整外壳（侧栏 + 主列顶栏 + 内容） |
| `HomePage.vue`（改） | 标签模式渲染 `AppHeader`，滚动模式交给外壳；标签模式结构**完全不变** |

## 4. 配色重做（同一套主题背景体系）

侧栏不再是独立色块，而是**在页面渐变上叠加一层低透明度蒙层**，文字使用主题文字变量：

| 变量 | 深色主题 | 浅色主题 |
| --- | --- | --- |
| `--rail-bg` | `rgba(14,12,34,.30)` | `rgba(255,255,255,.42)` |
| `--rail-border` | `rgba(255,255,255,.07)` | `rgba(74,70,148,.10)` |
| `--rail-hover` | `rgba(255,255,255,.06)` | `rgba(74,70,148,.05)` |
| `--rail-active` | `rgba(124,108,255,.17)` | `rgba(90,72,234,.12)` |
| `--rail-chip` | `rgba(255,255,255,.07)` | `rgba(74,70,148,.07)` |

- 文字/数量使用 `--text-sub` / `--text-main` / `--text-dim`，**浅色主题不再出现深色块**。
- 分割线降至 7–10% 透明度；无阴影、无渐变装饰、无大圆角。
- 当前分类为半透明柔和底（17% / 12%），不加边框、不加粗。

## 5. 对齐与空间

新增统一的间距令牌，所有区域共用同一套栅格：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--rail-width` / `--rail-width-collapsed` | `212px` / `60px` | 侧栏两态宽度 |
| `--rail-inset` | `12px` | 侧栏内部水平内边距 |
| `--shell-topbar-h` | `64px` | 顶栏与侧栏品牌行**同高**，形成贯穿整页的对齐线 |
| `--shell-gutter` | `clamp(14px, 2.4vw, 40px)` | 顶栏与内容**共用**的水平间距 |

实测对齐与空白（真实数据 10 分类 / 110 站点）：

| 指标 | V2.1.1 | 本次 |
| --- | --- | --- |
| 侧栏右边缘 → 内容左边缘（1440） | ≈54px | **0px**（内容紧贴侧栏，仅保留 gutter） |
| 侧栏右边缘 → 内容左边缘（1920） | ≈254px | **0px** |
| 分类标题左边界（1920） | ≈466px | **252px** |
| 时钟中心 = 内容列中心 | 否（各自居中） | ✅ 两者一致（818 = 818 @1440） |
| 顶栏高度 = 品牌行高度 | 不适用 | ✅ 64px = 64px |
| 横向溢出 | 无 | ✅ 无（1440 / 1920 / 834 / 390） |

## 7. 验证结果

| 检查 | 结果 |
| --- | --- |
| 前端单元测试 | ✅ **33 通过 / 0 失败**（布局契约用例由 7 增至 12，含"内容列不得二次居中"的回归守卫） |
| 前端类型检查 + 构建 | ✅ 通过 |
| 后端回归 | ✅ 115 通过 / 0 失败（本次未改后端） |
| 浏览器实测 | ✅ 1440 浅色/深色、1920 浅色、折叠、390 手机、标签模式回归；无 JS 错误 |
| 横向溢出 | ✅ 各断点均无 |

新增/更新的布局契约用例：

| 用例 | 断言 |
| --- | --- |
| 侧栏宽度区间 | `--rail-width` ∈ [200, 220] |
| 整列而非悬浮卡片 | `.rail` 含 `sticky` + `height:100vh`，无 `box-shadow` / `border-radius` |
| 整页外壳 | `.page--rail` 全宽；`.shell` 为 `grid` + `var(--rail-width) minmax(0,1fr)` |
| **内容不得二次居中** | `.shell__content` 不得出现 `margin: 0 auto` / `margin-inline: auto` / `max-width` / `width: min(100%…)` |
| 统一栅格 | `.shell__topbar` 与 `.shell__content` 共用 `var(--shell-gutter)` |
| 响应式 | ≤700px 隐藏侧栏并显示品牌与胶囊条；≤1080px 收为图标条 |
| 主题一致性 | 两种主题的 `--rail-bg` 均为低透明度 `rgba(...)`；浅色主题不得为深色块 |
